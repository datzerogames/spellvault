Como instalar

  1. Toque em Baixar o app. Se o navegador avisar que “este tipo de arquivo pode danificar o aparelho”, toque em Baixar mesmo assim.
  2. Abra o arquivo baixado. Na primeira vez, o Android pede para permitir a instalação de apps desta fonte: ative e volte.
  3. Toque em Instalar e depois em Abrir. Ao usar o scanner, permita o acesso à câmera.

Bom saber

O app não está na Play Store, por isso o Android faz esses avisos. O arquivo é este mesmo, publicado no GitHub. A coleção, os álbuns e as partidas ficam salvos só no seu celular: use Grimório › Exportar para guardar uma cópia de segurança. Precisa de internet para buscar cartas e imagens.

A demo é um app separado (pode ficar instalado junto com o completo): vem com dois álbuns 4x4 de Goblinóides já montados, o fichário em 3D e a Forja de decks. Os dados dela não se misturam com os do app completo.

Atualizações: este endereço e o QR code são fixos. Quando sair uma versão nova, ela aparece aqui, no mesmo botão.
